# admin-dashborad
A web based Warehourse Dashboard providing a simple overview of warehouse operations and activities. Built with HTML and CSS.

## Live Demo

https://nat0134.github.io/admin-dashboard/

## About The Project

This project demonstrates basic front-end web developement skiils using fundamental Hypertext Markup Language, Cascading style sheet and CSS grid module. 

## Purpose

Developed as a practical warehouse management system interface, focusing on a clean an daccessible dashboard for monitoring day-to-day warehourse operations.
